2. **Integrated Code Menu**: Place code redemption inside the primary Settings modal [00:22-00:23] instead of creating extra HUD clutter.
3. **Always-Visible Loadout Bar**: Display the 6-unit team bar continuously at the bottom of the hub HUD [00:23] so players can review their party while walking around.
4. **Open Sightlines from Spawn**: Position the spawn point facing directly toward primary progression portals [00:18].
5. **High-Contrast Portal Frames**: Frame portals with distinct colors (teal arches against yellow sand [00:18]) to draw player movement naturally.
