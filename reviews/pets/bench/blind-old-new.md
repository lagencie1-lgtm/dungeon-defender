# Blind test: old pets against new

Key (not shown to the judge): Set A = the NEW pets (cycle 5), Set B = the OLD pets (cycle 0). Gemini model gemini-3.6-flash.
Caution: the old set is rendered unlit on a dark ground, the new set lit on a grey ground; the judge was told to ignore that.

| Category | Set A | Set B |
| :--- | :---: | :---: |
| **Silhouette** | 8 | 4 |
| **Face appeal** | 9 | 3 |
| **Form quality** | 8 | 3 |
| **Surface** | 9 | 2 |
| **Rarity read** | 8 | 4 |
| **Set cohesion** | 9 | 6 |

### 1. Category Breakdown
* **Silhouette:** Set A uses expressive, distinct organic outlines; Set B relies on lazy, repetitive blobby primitives.
* **Face appeal:** Set A has polished, expressive eyes full of life; Set B features wide, derpy, copy-pasted eyes with zero charm.
* **Form quality:** Set A displays clean, hand-crafted volumes and smooth deforming geometry; Set B suffers from rigid shapes and harsh intersections.
* **Surface:** Set A uses gorgeous hand-painted textures with baked lighting; Set B relies on flat plastic fills and ugly tiled stone textures.
* **Rarity read:** Set A clearly scales from humble slimes to glowing, ornate legendaries; Set B's high-tier pets look cheap and flat.
* **Set cohesion:** Set A maintains a strict, premium art direction; Set B is consistently amateurish across all 12 models.

---

### 2. Overall Assessment
A 9–13 year old would choose **Set A by far**. Set A looks like a high-budget front-page game (*Adopt Me*, *Pet Simulator 99*), while Set B looks like a beginner Blender tutorial project. **Set A is vastly more professional.**

---

### 3. Set A Breakdown
**Three Weakest Pets:**
1. **Green Slime (Row 1):** Overly basic melted blob form with flat silhouette interest.
2. **Rock Dog (Row 3):** Stone texture on the ears and collar feels slightly muddy compared to the clean stylized fur on other pets.
3. **Sprout Creature (Row 2):** Simple spherical torso lacks the rich visual depth seen in the higher-tier pets.

**Three Strongest Pets:**
1. **Phoenix (Image 2, Row 5):** Vibrant, fiery gradients, dynamic feather silhouettes, and instant legendary appeal.
2. **Shadow Dragon (Image 2, Row 6):** Magnificent star-dusted wings and crisp, high-tier armor accents.
3. **Calico Cat (Image 1, Row 4):** Exceptional hand-painted fur layering with adorable flower accessories.

---

### 4. What Set B Does Better
The only advantage Set B has is **technical performance**. Its primitive geometry and untextured flat shaders use significantly fewer polygons and memory, meaning it would run smoother on low-end mobile devices—though the visual sacrifice is far too severe to justify it.
